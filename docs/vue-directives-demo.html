Part I v-uppercase-click • Text Uppercase on Click

Transforms text content to uppercase when clicked. Supports modifier .toggle to cycle between original case and uppercase, plus custom callbacks.

Standard Directive (v-uppercase-click):
👉 Click me: battle room #battle-8924-arena
With .toggle Modifier (click back and forth):
🔄 Click to toggle case: "two-sum-algorithmic-challenge"
Player Username Badges (Click each to uppercase):
🏆 alex_coder99 ⚔️ rival_master ⚡ hacker_bot
Input Element Support:
← Click the input field 
// Definition of v-uppercase-click
const uppercaseClickDirective = {
  mounted(el, binding) {
    el._originalText = el.textContent;
    el.style.cursor = 'pointer';
    el.addEventListener('click', () => {
      if (binding.modifiers.toggle && el._isUpper) {
        el.textContent = el._originalText;
        el._isUpper = false;
      } else {
        el.textContent = el.textContent.toUpperCase();
        el._isUpper = true;
      }
    });
  },
  unmounted(el) {
    el.removeEventListener('click', el._handler);
  }
};
